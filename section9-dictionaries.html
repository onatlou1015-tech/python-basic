📖 Section 9 · Digital Phonebook – Dictionaries

Key-Value pairs. Creating dictionaries. Accessing values via keys. Adding/updating entries. Looping through dictionaries (.items()).

The Ultimate Contact List

Imagine you have a physical phonebook. You look up a person's name (the key) and find their phone number (the value). You don't need to know where the information is stored—just the name, and you get the number instantly. That's exactly how dictionaries work in Python.

A dictionary is like a real-world dictionary too. You look up a word (the key) and get its definition (the value). It's a collection of key-value pairs where each key maps to a value. Unlike lists where you use numbers to find items, dictionaries use meaningful labels.

📘 By the end of this lesson, you will: understand key-value pairs create and manipulate dictionaries access values via keys add and update entries loop through dictionaries

A What is a Dictionary?

A dictionary stores data in key-value pairs. Each key is unique and acts as a label for its associated value.

Creating a dictionary:

# Empty dictionary phonebook = {} # Dictionary with data phonebook = { "Alice": "555-1234", "Bob": "555-5678", "Charlie": "555-9012" } # Dictionaries can store any data type student = { "name": "Alice", "age": 25, "grades": [85, 92, 78], "is_active": True } # Mixed keys (strings, numbers, tuples) mixed = { "name": "Bob", 42: "The Answer", (1, 2): "A tuple key" }

Visual representation:

phonebook = { "Alice": "555-1234", "Bob": "555-5678", "Charlie": "555-9012" } ↑ ↑ Keys Values

Key characteristics:

  • Keys must be immutable (strings, numbers, tuples)
  • Keys must be unique (no duplicates)
  • Values can be any data type (and can be duplicated)
  • Dictionaries are ordered (Python 3.7+ remembers insertion order)

B Accessing Values – The Key to Success

You access dictionary values using keys in square brackets [] or the .get() method.

Using square brackets (direct access):

phonebook = { "Alice": "555-1234", "Bob": "555-5678", "Charlie": "555-9012" } # Access by key alice_number = phonebook["Alice"] print(alice_number) # "555-1234" bob_number = phonebook["Bob"] print(bob_number) # "555-5678" # Warning: KeyError if key doesn't exist # diana_number = phonebook["Diana"] # KeyError!

Using .get() (safe access):

# .get() returns None if key doesn't exist diana_number = phonebook.get("Diana") print(diana_number) # None # Provide a default value if key doesn't exist diana_number = phonebook.get("Diana", "Not found") print(diana_number) # "Not found" alice_number = phonebook.get("Alice", "Not found") print(alice_number) # "555-1234"

Getting all keys or values:

phonebook = { "Alice": "555-1234", "Bob": "555-5678", "Charlie": "555-9012" } # Get all keys names = phonebook.keys() print(names) # dict_keys(['Alice', 'Bob', 'Charlie']) # Get all values numbers = phonebook.values() print(numbers) # dict_values(['555-1234', '555-5678', '555-9012']) # Get all key-value pairs as tuples items = phonebook.items() print(items) # dict_items([('Alice', '555-1234'), ...])

C Adding and Updating Entries

Dictionaries are mutable – you can add, update, and delete entries.

Adding new entries:

phonebook = { "Alice": "555-1234", "Bob": "555-5678" } # Add a new entry phonebook["Charlie"] = "555-9012" print(phonebook) # {'Alice': '555-1234', 'Bob': '555-5678', 'Charlie': '555-9012'} # Add multiple entries with update() phonebook.update({ "Diana": "555-3456", "Eve": "555-7890" }) print(phonebook) # {'Alice': '555-1234', 'Bob': '555-5678', 'Charlie': '555-9012', # 'Diana': '555-3456', 'Eve': '555-7890'}

Updating existing entries:

phonebook = { "Alice": "555-1234", "Bob": "555-5678" } # Update a value phonebook["Alice"] = "555-9999" print(phonebook) # {'Alice': '555-9999', 'Bob': '555-5678'} # Update with a new value phonebook["Bob"] = "555-0000" print(phonebook) # {'Alice': '555-9999', 'Bob': '555-0000'}

Using .setdefault() (add only if key doesn't exist):

phonebook = { "Alice": "555-1234" } # Add if key doesn't exist phonebook.setdefault("Bob", "555-5678") print(phonebook) # {'Alice': '555-1234', 'Bob': '555-5678'} # This doesn't change existing keys phonebook.setdefault("Alice", "555-9999") print(phonebook) # {'Alice': '555-1234', 'Bob': '555-5678'}

D Removing Entries

del

Remove by key

del dict[key]
phonebook = {"A": "123", "B": "456", "C": "789"} del phonebook["B"] # {"A": "123", "C": "789"} # del raises KeyError if key doesn't exist

.pop()

Remove and return value

value = dict.pop(key)
phonebook = {"A": "123", "B": "456"} removed = phonebook.pop("B") # removed = "456" # phonebook = {"A": "123"} # Provide default if key doesn't exist removed = phonebook.pop("C", "Not found") # "Not found"

.popitem()

Remove and return the last item

key, value = dict.popitem()
phonebook = {"A": "123", "B": "456"} last = phonebook.popitem() # last = ("B", "456") # phonebook = {"A": "123"}

.clear()

Remove all items

dict.clear()
phonebook = {"A": "123", "B": "456"} phonebook.clear() # {}

E Looping Through Dictionaries

Loop through keys:

phonebook = { "Alice": "555-1234", "Bob": "555-5678", "Charlie": "555-9012" } # Method 1: Direct iteration over keys for name in phonebook: print(f"{name}: {phonebook[name]}") # Method 2: Using .keys() (explicit) for name in phonebook.keys(): print(f"{name}: {phonebook[name]}") # Output: # Alice: 555-1234 # Bob: 555-5678 # Charlie: 555-9012

Loop through values:

# Loop through values only for number in phonebook.values(): print(number) # Output: # 555-1234 # 555-5678 # 555-9012

Loop through key-value pairs (using .items()):

# This is the most common pattern for name, number in phonebook.items(): print(f"Name: {name}, Number: {number}") # Output: # Name: Alice, Number: 555-1234 # Name: Bob, Number: 555-5678 # Name: Charlie, Number: 555-9012

Nested dictionaries and loops:

contacts = { "Alice": { "phone": "555-1234", "email": "alice@example.com", "age": 30 }, "Bob": { "phone": "555-5678", "email": "bob@example.com", "age": 25 } } # Loop through nested dictionary for name, info in contacts.items(): print(f"\nContact: {name}") for key, value in info.items(): print(f" {key}: {value}") # Output: # Contact: Alice # phone: 555-1234 # email: alice@example.com # age: 30 # Contact: Bob # phone: 555-5678 # email: bob@example.com # age: 25

📌 Golden Rules Summary

The 5 Golden Rules of Dictionaries:

  • Keys must be unique and immutable. Use strings, numbers, or tuples as keys. Lists cannot be keys (they're mutable).
  • Access values using keys, not positions. dict["key"] or dict.get("key", default). No such thing as "index 0" in a dictionary.
  • Use .get() for safe access. Avoids KeyError crashes. Provide a default for missing keys.
  • Loop with .items() for key-value pairs. for key, value in dict.items(): Most readable and efficient.
  • Dictionaries are mutable. Add, update, and delete entries freely. Changes affect the original dictionary.

⚠️ Common Mistakes & How to Avoid Them

Mistake 1: Using a list as a key

# Wrong - Lists are mutable and can't be keys my_dict = { ["name"]: "Alice" # TypeError: unhashable type: 'list' } # Correct - Use strings, numbers, or tuples my_dict = { "name": "Alice", (1, 2): "Value" }

Mistake 2: Assuming dictionary order (pre-Python 3.7)

# Dictionaries are ordered in Python 3.7+, but don't rely on it my_dict = {"a": 1, "b": 2, "c": 3} # Items are in insertion order, but this is not guaranteed in older versions # Use sorted() if order matters for key in sorted(my_dict.keys()): print(key, my_dict[key])

Mistake 3: Not using .get() and causing crashes

# Wrong - Crashes if key doesn't exist my_dict = {"name": "Alice"} age = my_dict["age"] # KeyError! # Correct - Safe access age = my_dict.get("age", 0) # Returns 0 if key doesn't exist

Mistake 4: Modifying a dictionary while iterating

# Danger - Changing size while iterating my_dict = {"a": 1, "b": 2, "c": 3} for key in my_dict: if key == "b": del my_dict[key] # RuntimeError! # Correct - Iterate over a copy for key in list(my_dict.keys()): if key == "b": del my_dict[key]

Mistake 5: Confusing .update() with assignment

# Wrong - This creates a new key called "update" my_dict = {"name": "Alice"} my_dict.update = {"age": 30} # Overwrites the method! # Correct - Use the method properly my_dict.update({"age": 30}) # Adds the key # Or assign directly my_dict["age"] = 30
