📦 Section 8 · Code Organizer – Writing Your Own Functions

Defining functions (def). Parameters and arguments. The return statement. Why do we use functions (DRY - Don't Repeat Yourself).

The Recipe Book of Programming

Imagine you're a chef in a busy restaurant. Every time a customer orders spaghetti, do you write down the entire recipe from scratch? No! You have a recipe card that you follow. When you need to make spaghetti, you just say "follow the spaghetti recipe" and all those steps happen automatically.

Functions are exactly like recipe cards in programming. They let you package a set of instructions into a single, reusable block. Instead of writing the same code over and over, you write it once in a function and then call that function whenever you need it.

A Why Functions? The DRY Principle

DRY stands for Don't Repeat Yourself. It's one of the most important principles in programming.

Without functions (repetitive and messy):

# Calculating the area of three rectangles # Rectangle 1 length1 = 5 width1 = 3 area1 = length1 * width1 print(f"Rectangle 1 area: {area1}") # Rectangle 2 length2 = 7 width2 = 4 area2 = length2 * width2 print(f"Rectangle 2 area: {area2}") # Rectangle 3 length3 = 6 width3 = 2 area3 = length3 * width3 print(f"Rectangle 3 area: {area3}")

With functions (clean and reusable):

def calculate_area(length, width): """Calculate the area of a rectangle.""" return length * width # Now use the function multiple times print(f"Rectangle 1 area: {calculate_area(5, 3)}") print(f"Rectangle 2 area: {calculate_area(7, 4)}") print(f"Rectangle 3 area: {calculate_area(6, 2)}")

Why functions matter:

  • Reusability: Write once, use many times.
  • Readability: Function names describe what the code does.
  • Maintainability: Fix a bug in one place, not everywhere.
  • Organization: Break complex problems into smaller pieces.
  • Testing: Test each function independently.

B Defining Functions – The def Keyword

Basic syntax:

def function_name(): """Optional docstring describing the function.""" # Code block # This code runs when the function is called

Simple example:

def greet(): """Print a greeting message.""" print("Hello! Welcome to Python!") # Call the function greet() greet() greet() # Output: # Hello! Welcome to Python! # Hello! Welcome to Python! # Hello! Welcome to Python!

The anatomy of a function:

def greet_user(name): # def + function name + parameters """Greet a user by name.""" # Docstring (optional but recommended) print(f"Hello, {name}!") # Function body (indented!) print("Nice to meet you!") # More function body # Calling the function greet_user("Alice")

C Parameters and Arguments – Passing Data

Parameters are the placeholders in the function definition. Arguments are the actual values you pass when calling the function.

def add_numbers(a, b): # a and b are parameters """Add two numbers and print the result.""" result = a + b print(f"{a} + {b} = {result}") # Calling with arguments add_numbers(5, 3) # 5 and 3 are arguments add_numbers(10, 7) # 10 and 7 are arguments add_numbers(100, 50) # Output: # 5 + 3 = 8 # 10 + 7 = 17 # 100 + 50 = 150

Multiple parameters:

def create_profile(name, age, city, occupation): """Create a user profile string.""" print(f"Name: {name}") print(f"Age: {age}") print(f"City: {city}") print(f"Occupation: {occupation}") print("-" * 30) create_profile("Alice", 30, "New York", "Engineer") create_profile("Bob", 25, "San Francisco", "Designer")

Default parameters (values that are optional):

def greet_user(name, greeting="Hello"): """Greet a user with a customizable greeting.""" print(f"{greeting}, {name}!") # Use the default greeting greet_user("Alice") # Hello, Alice! # Override the default greet_user("Bob", "Good morning") # Good morning, Bob! greet_user("Charlie", "Hey there") # Hey there, Charlie!

Real-world example:

def create_invoice(item, price, quantity=1, tax_rate=0.08): """Create an invoice for a purchase.""" subtotal = price * quantity tax = subtotal * tax_rate total = subtotal + tax print(f"Item: {item}") print(f"Quantity: {quantity}") print(f"Price per unit: ${price:.2f}") print(f"Subtotal: ${subtotal:.2f}") print(f"Tax ({(tax_rate * 100):.0f}%): ${tax:.2f}") print(f"Total: ${total:.2f}") print("-" * 30) # Use default tax rate create_invoice("Laptop", 999.99, 1) # Override tax rate create_invoice("Headphones", 49.99, 2, 0.05)

D The return Statement – Getting Results Back

return sends a value back to the caller. Without return, a function returns None by default.

Basic return:

def add(a, b): """Add two numbers and return the result.""" return a + b # The function returns a value that you can use result = add(5, 3) print(result) # 8 # You can use the return value directly print(add(10, 7)) # 17 # You can chain functions total = add(add(2, 3), add(4, 5)) print(total) # 14 (5 + 9)

Functions without return (return None):

def print_sum(a, b): """Print the sum (no return).""" print(a + b) def return_sum(a, b): """Return the sum (has return).""" return a + b # Print function - returns None result1 = print_sum(5, 3) # Prints: 8 print(result1) # Prints: None # Return function - returns a value result2 = return_sum(5, 3) # Nothing printed print(result2) # Prints: 8

Multiple return values:

def get_user_info(): """Return multiple values as a tuple.""" name = "Alice" age = 30 city = "New York" return name, age, city # Unpack the returned values name, age, city = get_user_info() print(f"Name: {name}, Age: {age}, City: {city}") # Or keep as a tuple info = get_user_info() print(info) # ("Alice", 30, "New York")

Early return (exit function early):

def divide(a, b): """Divide two numbers, handle division by zero.""" if b == 0: return "Error: Cannot divide by zero!" return a / b print(divide(10, 2)) # 5.0 print(divide(10, 0)) # Error: Cannot divide by zero!

F Scope – Where Variables Live

Variables have scope – they exist only in certain parts of your code.

Local variables: Created inside a function, only exist there.

def my_function(): local_var = "I'm local" print(local_var) # Works inside the function my_function() # print(local_var) # ERROR! local_var doesn't exist outside

Global variables: Created outside functions, accessible everywhere.

global_var = "I'm global" def show_global(): print(global_var) # Can read global variables def modify_global(): global global_var # Need 'global' to modify global_var = "Changed!" show_global() # I'm global modify_global() show_global() # Changed!

Parameter variables: Only exist inside the function.

def greet(name): # name is a parameter print(f"Hello, {name}!") greet("Alice") # print(name) # ERROR! name doesn't exist outside

Rules of scope:

  • Variables created inside a function stay inside (local).
  • Functions can read global variables but not modify them (unless using global).
  • Parameters are local variables.
  • Different functions can have variables with the same name – they don't conflict.

G Best Practices – Writing Good Functions

1. One function, one job (Single Responsibility)

❌ Bad - Does too many things

def process_user(name, age, city): validate_age(age) # Should be separate format_name(name) # Should be separate print(f"User: {name}, Age: {age}, City: {city}")

✅ Good - Each function does one thing

def validate_age(age): return 0 <= age <= 120 def format_name(name): return name.strip().title() def display_user(name, age, city): print(f"User: {name}, Age: {age}, City: {city}")

2. Use descriptive names

❌ Bad - What does this do?

def a(x, y): return x + y

✅ Good - Clear purpose

def calculate_total(price, tax_rate): return price + (price * tax_rate)

3. Add docstrings

def calculate_average(numbers): """ Calculate the average of a list of numbers. Args: numbers (list): A list of numbers. Returns: float: The average of the numbers. Example: >>> calculate_average([1, 2, 3, 4, 5]) 3.0 """ if not numbers: return 0 return sum(numbers) / len(numbers)

4. Use type hints (optional but helpful)

def add_numbers(a: float, b: float) -> float: """Add two numbers and return the result.""" return a + b def greet_user(name: str) -> None: """Greet a user by name.""" print(f"Hello, {name}!")

📌 Golden Rules Summary

The 5 Golden Rules of Functions:

  • DRY – Don't Repeat Yourself. If you're copying code, it belongs in a function. Write once, use many times.
  • Functions should do one thing well. Keep functions focused and small. If a function is getting long, break it apart.
  • Use return to send data back. Functions without return return None. Use return early for error handling.
  • Parameters are placeholders, arguments are actual values. def greet(name): → name is a parameter. greet("Alice") → "Alice" is an argument.
  • Variables have scope. Local variables stay inside functions. Use parameters to pass data into functions. Use return to get data out.

⚠️ Common Mistakes & How to Avoid Them

Mistake 1: Forgetting to call the function

# Wrong - Just the function name, no parentheses def greet(): print("Hello!") greet # Does nothing! No output! # Correct - Add parentheses to call greet() # Prints "Hello!"

Mistake 2: Not using return when needed

# Wrong - Just prints, doesn't return def add(a, b): print(a + b) result = add(5, 3) # Prints 8 print(result) # Prints None # Correct - Use return def add(a, b): return a + b result = add(5, 3) # Nothing printed print(result) # Prints 8

Mistake 3: Modifying global variables accidentally

# Wrong - This creates a local variable count = 0 def increment(): count = count + 1 # ERROR! count referenced before assignment # Correct - Use global or pass as parameter def increment_global(): global count count += 1 # Better - Pass as parameter def increment(count): return count + 1

Mistake 4: Forgetting to import the module

# Wrong - Function defined in another file but not imported # my_functions.py def greet(name): print(f"Hello, {name}!") # main.py greet("Alice") # NameError: name 'greet' is not defined # Correct - Import the function from my_functions import greet greet("Alice")

Mistake 5: Using mutable default parameters

# Danger - Mutable default parameters retain state! def add_item(item, items=[]): items.append(item) return items print(add_item("apple")) # ["apple"] print(add_item("banana")) # ["apple", "banana"] # Oops! # Correct - Use None as default def add_item(item, items=None): if items is None: items = [] items.append(item) return items print(add_item("apple")) # ["apple"] print(add_item("banana")) # ["banana"]
