🎵 Section 6 · My Playlist – Introduction to Lists

Creating lists. Indexing (starting at 0). Slicing basics ([start:end]). Appending, inserting, and removing items. Finding the length (len()).

Your Digital Backpack

Imagine you have a backpack. You can put items in it, take items out, check what's inside, and even organize things in a specific order. A list in Python is exactly like that—a container that can hold multiple items in a specific sequence.

Think of your music playlist. You add songs, remove songs, reorder them, and skip to specific tracks. Lists give you this same power for any type of data.

📘 By the end of this lesson, you will: create and name lists access items with indexing extract portions with slicing add and remove items find length with len()

A What is a List?

A list is a collection of items stored in a specific order. You can put any type of data in a list—strings, numbers, even other lists!

Creating a list:

# Empty list playlist = [] # List of strings songs = ["Bohemian Rhapsody", "Imagine", "Hotel California"] # List of numbers ages = [25, 30, 18, 42] # Mixed types (allowed but not recommended) mixed = ["Hello", 42, 3.14, True] # List of lists (nested lists) matrix = [[1, 2], [3, 4], [5, 6]]

Visual representation:

songs = ["Bohemian Rhapsody", "Imagine", "Hotel California"] ↑ ↑ ↑ Index 0 Index 1 Index 2

Real-world example:

# Creating your music playlist my_playlist = ["Shape of You", "Blinding Lights", "Dance Monkey", "Levitating"] print(my_playlist) # Output: ['Shape of You', 'Blinding Lights', 'Dance Monkey', 'Levitating']

B Indexing – Finding Items by Position

Each item in a list has a position number called an index. Important: Indexing starts at 0, not 1!

Basic indexing:

playlist = ["Song A", "Song B", "Song C", "Song D", "Song E"] # Positive indexing (from the start) first = playlist[0] # "Song A" second = playlist[1] # "Song B" third = playlist[2] # "Song C" last = playlist[4] # "Song E" # Negative indexing (from the end) last = playlist[-1] # "Song E" second_last = playlist[-2] # "Song D" first = playlist[-5] # "Song A"

Visual guide to indexing:

Index: 0 1 2 3 4 List: ["A", "B", "C", "D", "E"] Negative: -5 -4 -3 -2 -1

Common indexing mistakes:

playlist = ["A", "B", "C"] # Wrong - Index out of range (list has no index 3) song = playlist[3] # IndexError! # Wrong - Index out of range (list has no index -4) song = playlist[-4] # IndexError! # Correct - Valid indices are 0, 1, 2 and -1, -2, -3 song = playlist[2] # "C" song = playlist[-1] # "C"

Practical example:

# Creating a student roster students = ["Alice", "Bob", "Charlie", "Diana", "Eve"] print(f"First student: {students[0]}") print(f"Last student: {students[-1]}") print(f"Middle student: {students[2]}") # Output: # First student: Alice # Last student: Eve # Middle student: Charlie

C Slicing – Getting Subsets of a List

Slicing lets you extract a portion of a list, creating a new list with those items.

Syntax: list[start:end] – starts at start, stops before end

playlist = ["A", "B", "C", "D", "E", "F", "G"] # Basic slicing first_three = playlist[0:3] # ["A", "B", "C"] middle = playlist[2:5] # ["C", "D", "E"] last_two = playlist[5:7] # ["F", "G"] # Omitting start (starts from beginning) first_three = playlist[:3] # ["A", "B", "C"] # Omitting end (goes to end) last_three = playlist[4:] # ["E", "F", "G"] # Negative indices in slicing last_two = playlist[-2:] # ["F", "G"] middle_three = playlist[2:-2] # ["C", "D", "E"] # Copying an entire list full_copy = playlist[:] # ["A", "B", "C", "D", "E", "F", "G"]

Visual guide to slicing:

List: ["A", "B", "C", "D", "E", "F", "G"] Index: 0 1 2 3 4 5 6 Slices: [0:3] → [A, B, C] [2:5] → [C, D, E] [4:] → [E, F, G] [:3] → [A, B, C] [-3:] → [E, F, G]

Slicing with step (skip items):

playlist = ["A", "B", "C", "D", "E", "F", "G"] # Every other item every_other = playlist[0:7:2] # ["A", "C", "E", "G"] # Reverse the list reversed_list = playlist[::-1] # ["G", "F", "E", "D", "C", "B", "A"] # Every second item from index 1 to 6 step_slice = playlist[1:6:2] # ["B", "D", "F"]

Practical example:

# Getting top 3 songs from a playlist songs = ["Song 1", "Song 2", "Song 3", "Song 4", "Song 5"] top_3 = songs[0:3] print(f"Top 3 songs: {top_3}") # Getting the last 2 songs recent = songs[-2:] print(f"Recently added: {recent}") # Getting songs 2 through 4 (index 1 to 3) middle = songs[1:4] print(f"Middle songs: {middle}")

D Modifying Lists – Adding and Removing Items

Lists are mutable, meaning you can change them after creation.

Adding Items:

append()

Adds an item to the end

list.append(item)
playlist = ["A", "B"] playlist.append("C") # ["A", "B", "C"]

insert()

Adds an item at a specific position

list.insert(index, item)
playlist = ["A", "C"] playlist.insert(1, "B") # ["A", "B", "C"] playlist.insert(0, "Intro") # ["Intro", "A", "B", "C"]

extend()

Adds multiple items from another list

list.extend(iterable)
playlist = ["A", "B"] new_songs = ["C", "D"] playlist.extend(new_songs) # ["A", "B", "C", "D"]

Removing Items:

remove()

Removes the first occurrence of a value

list.remove(value)
playlist = ["A", "B", "C", "B"] playlist.remove("B") # ["A", "C", "B"]

pop()

Removes and returns an item by index

list.pop(index)
playlist = ["A", "B", "C"] last = playlist.pop() # last = "C", playlist = ["A", "B"] first = playlist.pop(0) # first = "A", playlist = ["B"]

del

Deletes items or the entire list

del list[index]
playlist = ["A", "B", "C", "D"] del playlist[0] # ["B", "C", "D"] del playlist[1:3] # ["B"] del playlist # NameError: list not defined

clear()

Removes all items (keeps the list)

list.clear()
playlist = ["A", "B", "C"] playlist.clear() # []

⚠️ Important notes:

  • remove() raises ValueError if the item doesn't exist.
  • pop() with no index removes the last item.
  • del can delete slices or the entire list.
  • clear() removes all items but keeps the list variable.

E Finding the Length – The len() Function

len() tells you how many items are in a list.

playlist = ["Song A", "Song B", "Song C", "Song D"] count = len(playlist) print(f"Number of songs: {count}") # Number of songs: 4 # Useful for loops for i in range(len(playlist)): print(f"Track {i+1}: {playlist[i]}") # Output: # Track 1: Song A # Track 2: Song B # Track 3: Song C # Track 4: Song D

Common len() patterns:

# Check if list is empty if len(playlist) == 0: print("Your playlist is empty!") # Get the last item safely if len(playlist) > 0: last = playlist[-1] print(f"Last song: {last}") # Create a range based on list length for i in range(len(playlist) - 1, -1, -1): # Reverse order print(playlist[i])

F Other Useful List Operations

Checking if an item exists:

playlist = ["Song A", "Song B", "Song C"] if "Song B" in playlist: print("Song B is in the playlist!") if "Song Z" not in playlist: print("Song Z is not in the playlist!")

Finding the index of an item:

# Finding the index of an item index = playlist.index("Song B") print(f"Song B is at position {index}") # 1

Counting occurrences:

playlist = ["Song A", "Song B", "Song A", "Song C", "Song A"] count_a = playlist.count("Song A") print(f"Song A appears {count_a} times") # 3

Sorting and reversing:

numbers = [3, 1, 4, 1, 5, 9, 2] # Sort in place (modifies the list) numbers.sort() print(numbers) # [1, 1, 2, 3, 4, 5, 9] # Sort in reverse numbers.sort(reverse=True) print(numbers) # [9, 5, 4, 3, 2, 1, 1] # Reverse the list (reverses order) numbers.reverse() print(numbers) # [1, 1, 2, 3, 4, 5, 9] # Get a sorted copy without modifying original original = [3, 1, 4] sorted_copy = sorted(original) print(sorted_copy) # [1, 3, 4] print(original) # [3, 1, 4] (unchanged)

📌 Golden Rules Summary

The 5 Golden Rules of Lists:

  • Indexing starts at 0. The first item is at list[0], not list[1]. The last item is at list[-1] or list[len(list) - 1].
  • Slicing stops before the end index. list[0:3] gives items at indices 0, 1, 2 (not 3). Omitting start or end gives the default boundaries.
  • Lists are mutable. You can change, add, and remove items after creation. Operations like append(), insert(), and pop() modify the original list.
  • len() is your friend. Always use len(list) to find the number of items. Use it for safe indexing and loop control.
  • Be careful with indices. Accessing an index that doesn't exist raises an IndexError. Always check that your index is within 0 to len(list) - 1.

⚠️ Common Mistakes & How to Avoid Them

Mistake 1: Off-by-one errors with indexing

# Wrong - Expecting last item at index len(list) playlist = ["A", "B", "C"] last = playlist[3] # IndexError! # Correct - Last item is at len(list) - 1 last = playlist[2] # "C" last = playlist[-1] # "C"

Mistake 2: Modifying a list while iterating over it

# Danger - This will skip items playlist = ["A", "B", "C", "D"] for song in playlist: if song == "B": playlist.remove(song) # Modifying while iterating! # Safer - Create a copy or use list comprehension playlist = ["A", "B", "C", "D"] for song in playlist[:]: # Iterate over a copy if song == "B": playlist.remove(song)

Mistake 3: Confusing append() with extend()

# Wrong - Adds the list itself as one item playlist = ["A", "B"] playlist.append(["C", "D"]) print(playlist) # ["A", "B", ["C", "D"]] # Correct - Adds each item individually playlist = ["A", "B"] playlist.extend(["C", "D"]) print(playlist) # ["A", "B", "C", "D"]

Mistake 4: Using remove() when item might not exist

# Wrong - Crashes if item not found playlist = ["A", "B", "C"] playlist.remove("Z") # ValueError! # Correct - Check first if "Z" in playlist: playlist.remove("Z") else: print("Item not found")

Mistake 5: Slicing with out-of-range indices

# Slicing is forgiving - it just returns whatever exists playlist = ["A", "B", "C"] result = playlist[1:10] # ["B", "C"] - no error! result = playlist[-10:3] # ["A", "B", "C"] - no error!
