The Art of "Keep Going Until..."

Imagine you're playing hide and seek. You don't know how many times you'll need to search before finding your friend. You just keep looking until you find them. That's exactly what a while loop does—it keeps repeating while a condition is true, and you don't always know how many times that will be.

While loops are perfect for interactive programs that need to keep running until the user says "stop," or for situations where the number of repetitions depends on user input or random events.

📘 By the end of this lesson, you will: use while loops avoid infinite loops use break to exit import the random module build a complete game

A while Loops – The "Don't Know When to Stop" Loop

A while loop repeats as long as a condition is True. It's like telling a friend: "Keep walking while I'm not there yet."

Basic syntax:

while condition: # Code to run repeatedly # Keep running WHILE condition is True # Stop when condition becomes False

Simple example:

counter = 0 while counter < 5: print(f"Count: {counter}") counter += 1 # Increment counter print("Done!") # Output: # Count: 0 # Count: 1 # Count: 2 # Count: 3 # Count: 4 # Done!

Visual comparison:

for loop (known number of times)

Repeat 5 times → [1][2][3][4][5] → Stop

while loop (unknown number of times)

Keep going while condition is True
→ [1][2][3]... [?] → Stop when condition becomes False

B for vs. while – When to Use Which

Use a for loop when:

  • You know exactly how many times to repeat.
  • You're iterating through a sequence (list, string, range).
  • You want to process each item in a collection.
# For loop - known number of iterations for i in range(10): print(i) # Exactly 10 times # For loop - iterating through a list for fruit in ["apple", "banana", "cherry"]: print(fruit) # Exactly 3 times

Use a while loop when:

  • You don't know how many times to repeat.
  • The repetition depends on user input or dynamic conditions.
  • You need to keep running until something changes.
# While loop - continues until user says stop user_input = "" while user_input != "quit": user_input = input("Type something (or 'quit' to stop): ") print(f"You typed: {user_input}") # While loop - continues until random condition is met import random roll = 0 while roll != 6: roll = random.randint(1, 6) print(f"Rolled: {roll}")

C Infinite Loops – The Danger Zone

An infinite loop is a loop that never stops. It happens when the condition never becomes False.

⚠️ WARNING: Infinite loop example (NEVER RUN THIS!):

# DANGER! This will run forever! while True: print("Help! I'm stuck!") # No way to exit! Your program will freeze!

How to fix common infinite loop mistakes:

Mistake 1: Forgetting to update the condition

# Wrong - Infinite loop count = 0 while count < 5: print(count) # count never changes! It stays 0 forever! # Correct - Update the variable count = 0 while count < 5: print(count) count += 1 # NOW the condition will eventually become False

Mistake 2: Wrong condition logic

# Wrong - Infinite loop password = "secret" user_input = "" while user_input != password: print("Wrong password!") # This runs forever! # Need to ask for input again inside the loop! # Correct - Ask for input inside the loop password = "secret" user_input = "" while user_input != password: user_input = input("Enter password: ") if user_input != password: print("Wrong password! Try again.")

Mistake 3: Using = instead of == in conditions

# Wrong - This assigns, never becomes False x = 0 while x = 5: # Syntax error or infinite loop! print(x) # Correct - Compare properly x = 0 while x != 5: # Or while x < 5 print(x) x += 1

D The break Statement – Emergency Exit

break lets you exit a loop immediately, even if the condition is still True. It's like hitting the emergency stop button.

Basic usage:

while True: # Infinite loop (on purpose!) user_input = input("Enter a number (or 'quit' to exit): ") if user_input == "quit": break # Exit the loop immediately print(f"You entered: {user_input}") print("Loop ended!")

Real-world example: Password system with limited attempts:

password = "python123" attempts = 0 max_attempts = 3 while attempts < max_attempts: guess = input("Enter password: ") attempts += 1 if guess == password: print("Access granted! Welcome!") break # Exit on success else: remaining = max_attempts - attempts print(f"Wrong password. {remaining} attempts remaining.") if attempts == max_attempts: print("Too many failed attempts. Account locked.")

Using break in a number guessing game:

import random secret = random.randint(1, 10) print("I'm thinking of a number between 1 and 10.") while True: # Keep going until the user guesses guess = int(input("Your guess: ")) if guess == secret: print("You got it! Congratulations!") break # Exit the game elif guess < secret: print("Too low! Try again.") else: print("Too high! Try again.")

E Importing Modules – import random

Modules are pre-written code libraries that add extra functionality to Python. You need to import them before you can use them.

The random module provides functions for generating random numbers and choices.

Basic usage:

import random # Generate a random integer between 1 and 10 (inclusive) number = random.randint(1, 10) print(number) # Random float between 0 and 1 decimal = random.random() print(decimal) # Random choice from a list colors = ["red", "blue", "green", "yellow"] choice = random.choice(colors) print(choice) # Shuffle a list cards = [1, 2, 3, 4, 5] random.shuffle(cards) print(cards) # Random order

Common random functions:

Function Description Example
random.randint(a, b) Random integer between a and b (inclusive) random.randint(1, 6) → 4
random.random() Random float between 0 and 1 random.random() → 0.732
random.choice(list) Random item from a list random.choice(["A", "B", "C"]) → "B"
random.shuffle(list) Shuffles a list in place random.shuffle(cards) → shuffles
random.uniform(a, b) Random float between a and b random.uniform(1.0, 5.0) → 3.72

Importing specific functions:

# Option 1: Import the whole module import random roll = random.randint(1, 6) # Option 2: Import specific functions (cleaner!) from random import randint, choice, shuffle roll = randint(1, 6) # No "random." needed! color = choice(["red", "blue"])

📌 Golden Rules Summary

The 5 Golden Rules of While Loops:

  • Always ensure the condition can become False. Update variables inside the loop to eventually stop it. Use a counter, wait for user input, or break.
  • Use break to exit loops immediately. Perfect for "quit" commands or finding a match. But don't overuse it—it can make code hard to follow.
  • Avoid infinite loops by checking your conditions carefully. Test your code with small values first. Add a safety counter or timeout if needed.
  • Import modules at the top of your file. Place import statements before your main code. It's a convention that makes your code cleaner.
  • Use try/except for user input to prevent crashes. Users make mistakes—handle them gracefully. Never assume input will be perfect.

⚠️ Common Mistakes & How to Avoid Them

Mistake 1: Forgetting to update loop variables

# Wrong - Infinite loop num = 0 while num < 10: print(num) # num never changes! # Correct - Update the variable while num < 10: print(num) num += 1 # Increment

Mistake 2: Incorrect condition logic

# Wrong - This skips 0 and never prints it num = 0 while num > 10: # 0 > 10 is False, loop never runs! print(num) # Correct - Use the right condition while num < 10: print(num) num += 1

Mistake 3: Using break when you could use the condition

# Overkill - Break not needed here num = 0 while True: if num >= 5: break print(num) num += 1 # Cleaner - Use the condition num = 0 while num < 5: print(num) num += 1

Mistake 4: Forgetting to convert user input

# Wrong - Comparing string to integer secret = 42 guess = input("Guess: ") # "42" (string) if guess == secret: # False! "42" != 42 print("You win!") # Correct - Convert to integer guess = int(input("Guess: ")) # 42 (integer) if guess == secret: # True! print("You win!")

Mistake 5: Not handling invalid input

# Crashes - User types "abc" num = int(input("Enter a number: ")) # ValueError! # Handles errors - Try/except try: num = int(input("Enter a number: ")) except ValueError: print("That's not a valid number!")
