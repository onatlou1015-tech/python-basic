The input() function. Type conversion (int(), str()). Using f-strings for clean output. Concatenation.

Making Your Program Talk Back

Imagine you're a radio host. You ask a question, your guest answers, and then you respond based on what they said. A one-way conversation is boring—the magic happens when there's interaction.

That's exactly what input() does for your code. It turns your program from a monologue into a dialogue. Your program can ask for information, remember it, and then use it to personalize its response.

📘 By the end of this lesson, you will: capture user input with input() convert data types safely format output with f-strings understand concatenation

A The input() Function – Your Program's Ears

The input() function pauses your program and waits for the user to type something and press Enter. Whatever they type comes back as a string (text).

Syntax example:

# Syntax example name = input("What is your name? ") print(name)
  • The text inside the parentheses "What is your name? " is the prompt – it tells the user what to type.
  • The program pauses and waits.
  • The user types something (e.g., "Alice") and presses Enter.
  • Whatever was typed gets stored in the variable name.
  • The program continues and prints the name.

⚠️ Important: input() ALWAYS returns a string. Even if the user types a number, Python treats it as text.

age = input("Enter your age: ") # User types: 25 print(age + 5) # ERROR! You can't add a string and a number.

B Type Conversion – Making Data Behave

Since input() always gives you strings, you need to convert them when you want numbers.

Converting to an Integer:

# Converting to an Integer age = input("Enter your age: ") # "25" (string) age = int(age) # 25 (integer) print(age + 5) # Outputs: 30

Converting to a Float:

# Converting to a Float price = input("Enter the price: ") # "19.99" (string) price = float(price) # 19.99 (float) print(price * 2) # Outputs: 39.98

Converting to a String (rarely needed but good to know):

# Converting to a String number = 42 text = str(number) # "42"

💡 You can combine input and conversion in one line:

age = int(input("Enter your age: "))

⚠️ But be careful! If the user types letters when you expect a number, your program will crash. We'll learn how to handle that later!

C f-Strings – The Clean Way to Combine Text

When you want to mix variables with text, you have two main options.

Option 1: Concatenation (The "Old" Way)

Concatenation means joining strings together using the + operator.

name = "Alice" age = 30 print("Hello, " + name + "! You are " + str(age) + " years old.") # Outputs: Hello, Alice! You are 30 years old.
  • Problems with concatenation:
  • You must convert non-strings manually (str(age)).
  • Many + signs make it hard to read.
  • Easy to forget spaces.

Option 2: f-Strings (The "Modern" Way) – RECOMMENDED

An f-string lets you embed variables directly inside a string by putting an f before the quotes and using { } curly braces.

name = "Alice" age = 30 print(f"Hello, {name}! You are {age} years old.") # Outputs: Hello, Alice! You are 30 years old.
  • Why f-strings are better:
  • ✅ No need to convert numbers—Python does it automatically.
  • ✅ Much cleaner and easier to read.
  • ✅ You can even do math inside the braces!

Example with math inside f-string:

price = 19.99 quantity = 3 print(f"Total cost: ${price * quantity}") # Outputs: Total cost: $59.97

Real-world comparison:

# Without f-strings (messy) print("Welcome, " + name + ". Your score is " +str(score) + " out of " + str(total) + ".") # With f-strings (clean!) print(f"Welcome, {name}. Your score is {score} out of {total}.")

D Bringing It All Together – The Interactive Chatbot

Let's build a simple program that asks for the user's name and age, then responds with personalized information.

Interactive Chatbot:

# Ask for user input name = input("What is your name? ") age = int(input("How old are you? ")) # Calculate future age future_age = age + 10 # Respond using f-strings print(f"Hello, {name}! Nice to meet you.") print(f"You are currently {age} years old.") print(f"In 10 years, you will be {future_age} years old.")

Sample run:

What is your name? Alex How old are you? 25 Hello, Alex! Nice to meet you. You are currently 25 years old. In 10 years, you will be 35 years old.

Now with multiple data types:

# Collect information name = input("Enter student name: ") grade = float(input("Enter grade average: ")) classes = int(input("Enter number of classes: ")) # Display using f-string print(f"Student: {name}") print(f"Grade Average: {grade}%") print(f"Total Classes: {classes}") print(f"{name} is taking {classes} classes with an average of {grade}%.")

🎯 Key pattern: Input → Convert → Store → Output using f-strings

📌 Golden Rules for Input & f-Strings

Remember these 3 rules:

  • input() always returns a string. If you need a number, convert it immediately.
    age = int(input("Age: ")) # Good price = float(input("Price: ")) # Good
  • f-strings start with f and use {} for variables. Don't forget the f!
    print(f"Hello {name}") # Correct print("Hello {name}") # Wrong - prints literally "{name}"
  • Be careful with user errors. If someone types "twenty" instead of "20", int() will crash your program. Always assume users will make mistakes!
