🐍 Section 1 · "Hello, World!" – The Absolute Basics

What is code? Syntax vs. natural language. The print() function. Variables (strings, integers, floats). Rules for naming variables.

Speaking the Language of Computers

Imagine you are a master chef, but your kitchen appliance only understands French. If you shout "Turn on!" in English, nothing happens. To cook, you must learn the appliance's specific French commands.

Coding is exactly that. Code is a set of instructions written in a programming language (like Python) that tells a computer exactly what to do.

📘 By the end of this lesson, you will: understand code vs. human speech write your first print() store data in variables golden rules for naming

A Syntax vs. Natural Language

Human language (English, Spanish, etc.) is full of context, slang, and ambiguity.

Example: "I saw the man with the telescope." (Did I have the telescope, or did he?)

  • Syntax is the strict, unbreakable grammar of a programming language.
  • In Python, you must use a colon : for certain statements.
  • You must use parentheses () to call functions.
  • If you miss a single quotation mark ", the entire program crashes.

B Your First Command – The print() Function

A function is a pre-built tool in Python that does a specific job. The print() function outputs text or numbers to your screen.

Syntax example:

print("Hello, World!")
  • print is the command.
  • The parentheses () hold the instruction.
  • The quotation marks " " tell Python this is plain text.

C Variables – The Storage Boxes

A variable is a named container used to store data in the computer's memory.

Data Types (What goes inside the box):

  • Strings (str): Text. Must always be wrapped in quotes.
    name = "Alice"
  • Integers (int): Whole numbers (no decimals). No quotes needed.
    age = 30
  • Floats (float): Numbers with decimals. No quotes needed.
    price = 19.99

# Example in Action

greeting = "Hello" # String score = 10 # Integer pi = 3.14 # Float print(greeting) # Outputs: Hello print(score + 5) # Outputs: 15

D The 5 Golden Rules for Naming Variables

📌 Golden Rules

  • Must start with a letter (a-z, A-Z) or an underscore _.
    score, Name ✓   1st_place ✗
  • Can only contain letters, numbers, and underscores.
    My_score ✓   my-score ✗
  • Case-sensitive. age and Age are different.
  • Cannot use Python's "Reserved Keywords" (print, if, while, etc.)
  • Be descriptive! p is legal, but price_of_coffee is better.

📌 Today, you learned that coding is about giving precise instructions using strict syntax. You can output data using print(), and store different types of data (Strings, Integers, Floats) inside variables.
