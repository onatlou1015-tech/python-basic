🧠 Section 3 · The Decision Maker – Conditional Statements

Boolean logic (True/False). Comparison operators (==, !=, >, <). if, elif, and else blocks. Indentation rules.

Giving Your Program a Brain

Imagine you're a bouncer at an exclusive club. You check each person: "Are you over 21? Do you have an ID? Are you on the guest list?" Based on the answers, you make a decision—let them in or turn them away.

Your program needs this same ability. Without decisions, every program runs the same way every time—like a movie that plays the same scenes repeatedly. With decisions, your program becomes interactive and intelligent, responding differently based on the situation.

📘 By the end of this lesson, you will: understand Boolean values use comparison operators write if/elif/else statements master indentation rules

A Boolean Logic – The Language of Decisions

At the heart of every decision is a simple question with only two possible answers: Yes (True) or No (False).

In Python, these are called Booleans (named after George Boole, a mathematician who invented this logic system).

is_raining = True is_sunny = False print(is_raining) # Outputs: True print(is_sunny) # Outputs: False

Where Booleans come from:

Booleans usually come from comparisons—asking Python to compare two values.

age = 25 is_adult = age >= 18 # True (25 is greater than 18) can_retire = age >= 65 # False (25 is not greater than 65) print(is_adult) # True print(can_retire) # False

💡 Think of it like this: Every question you ask the computer returns either True or False.

age >= 18 is like asking: "Is age greater than or equal to 18?"

The computer answers: "True!" or "False!"

B Comparison Operators – Asking Questions

These are the tools you use to ask questions in Python.

Operator Meaning Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
> Greater than 10 > 5 True
< Less than 10 < 5 False
>= Greater than or equal to 10 >= 10 True
<= Less than or equal to 10 <= 9 False

⚠️ WARNING: = vs ==

  • = is for assignment (putting a value in a variable).
  • == is for comparison (asking if two things are equal).
# WRONG - This assigns 18 to age (always True in a condition!) if age = 18: print("You're 18") # CORRECT - This asks if age equals 18 if age == 18: print("You're 18")

Real-world comparison examples:

score = 85 grade = "A" print(score > 70) # True print(score == 100) # False print(grade != "F") # True print(grade == "A") # True # You can even compare strings! name = "Alice" print(name == "Alice") # True (case-sensitive!) print(name == "alice") # False (different case)

C The if Statement – Making the First Decision

The if statement is the most basic decision-maker. It checks a condition. If it's True, it runs the code block. If it's False, it skips it.

Syntax:

if condition: # Code to run if condition is True # This must be INDENTED!

Simple example:

age = 18 if age >= 18: print("You can vote!") # This runs because age >= 18 is True

What if the condition is False?

age = 16 if age >= 18: print("You can vote!") # This is SKIPPED (nothing runs)

Multiple if statements (each checked separately):

temperature = 75 if temperature > 80: print("It's hot outside!") if temperature > 60: print("It's warm outside!") # This runs if temperature < 40: print("It's cold outside!") # Output: # It's warm outside!

D The else Statement – The Alternative Path

else gives you a fallback option. If the if condition is False, the else block runs.

Syntax:

if condition: # Runs if True else: # Runs if False

Example:

age = 16 if age >= 18: print("You can vote!") else: print("You're too young to vote.") print("Wait", 18 - age, "more years.") # Output: # You're too young to vote. # Wait 2 more years.

💡 Important: else has NO condition—it's the "catch-all" for everything that doesn't match the if.

E The elif Statement – Multiple Choices

What if you have more than two possibilities? That's where elif (short for "else if") comes in. It lets you check multiple conditions in order.

Syntax:

if condition1: # Runs if condition1 is True elif condition2: # Runs if condition1 is False AND condition2 is True elif condition3: # Runs if condition1 and condition2 are False AND condition3 is True else: # Runs if ALL conditions are False

Example – The Grading System:

score = 85 if score >= 90: grade = "A" print("Excellent!") elif score >= 80: grade = "B" print("Good job!") elif score >= 70: grade = "C" print("Not bad.") elif score >= 60: grade = "D" print("You need to study more.") else: grade = "F" print("You failed. Seek help!") print(f"Your grade is: {grade}") # Output: # Good job! # Your grade is: B

How Python processes this:

  • Checks score >= 90 → False (85 is not >= 90) → Move on
  • Checks score >= 80 → True (85 is >= 80) → RUNS THIS BLOCK, then SKIPS everything else
  • The remaining elif and else are ignored

⚠️ CRITICAL: Order matters!

# WRONG ORDER - This never reaches "A" score = 95 if score >= 70: # This is True! grade = "C" elif score >= 80: # This is never checked grade = "B" elif score >= 90: # This is never checked grade = "A" print(grade) # Outputs: C (WRONG!) # CORRECT ORDER - Check highest first if score >= 90: grade = "A" elif score >= 80: grade = "B" elif score >= 70: grade = "C"

F The Golden Rule of Python – INDENTATION

Indentation is NOT optional in Python. It's how Python knows which code belongs to which block.

The Rule: All code inside an if, elif, or else must be indented by 4 spaces (or a Tab).

Correct:

if age >= 18: # ← Colon here print("Adult") # ← 4 spaces/Tab (inside the if) print("You can vote") # ← 4 spaces/Tab (still inside) print("Program ends") # ← No indent (outside the if)

Wrong:

if age >= 18: print("Adult") # ❌ IndentationError! print("You can vote") # ❌ IndentationError!

Nested conditions (if inside an if):

age = 25 has_id = True if age >= 18: print("Age check passed.") if has_id: print("You may enter the club!") # Inside BOTH ifs else: print("You need an ID.") # Inside first if, inside else else: print("Too young.") # Inside first if's else

The indentation visually shows the structure:

if age >= 18: ← Level 0 if has_id: ← Level 1 (indented) print("Enter") ← Level 2 (indented further) else: ← Level 1 (same as inner if) print("No ID") ← Level 2 else: ← Level 0 (same as outer if) print("Too young") ← Level 1

📌 Golden Rules Summary

The 5 Golden Rules of Conditional Statements:

  • Use == for comparison, = for assignment.
    if age == 18: # correct if age = 18: # error!
  • Always use a colon : at the end of if, elif, and else.
    if condition: # correct if condition # error!
  • Indent your code inside blocks with 4 spaces. Python uses indentation instead of { } like other languages. Mixing tabs and spaces causes errors!
  • Check the most specific conditions first. Highest to lowest (e.g., >= 90, then >= 80, then >= 70).
  • elif and else are optional, but always use if first. if → elif → elif → else (only one if, any number of elifs, one else).

⚠️ Common Mistakes & How to Avoid Them

Mistake 1: Forgetting the colon

if age > 18 # ❌ SyntaxError: Missing colon print("Adult")

Mistake 2: Inconsistent indentation

if age > 18: print("Adult") print("Still inside?") # ❌ IndentationError: Inconsistent

Mistake 3: Using = instead of ==

if age = 18: # ❌ This assigns, doesn't compare! print("You're 18")

Mistake 4: Wrong order of conditions

score = 95 if score >= 70: # ❌ This catches everything above 70 grade = "C" elif score >= 90: # ❌ Never runs grade = "A"
